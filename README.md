# SK Cyber Hub — SAAD YOUSUF KAKAR

A zero-budget, mobile-friendly digital discovery platform aiming to serve Pakistan, Saudi Arabia, Urdu-speaking communities and a wider global audience.

## Live site
https://habibullah-hub.github.io/SAAD-YOUSUF-KAKAR-Ultimate-/

## Current public directory
- Android apps and official app-store links
- AI tools
- Free browser-based online tools
- Software and open-source resources
- Documents and learning resources
- Games
- Technology and international news links
- Responsive Microsoft Store-inspired light interface
- Category navigation, instant client-side search and mobile layouts
- Basic SEO metadata, structured WebSite data, robots.txt and sitemap.xml
- About, privacy and advertising/affiliate disclosure pages

## Run locally
Open `index.html` in a browser. The current directory is static HTML/CSS/JavaScript and does not require a build step.

## Current technical limits
- The current repository contains a static website. There is no authenticated admin dashboard, member account system, payment flow, wallet, server-side search, or database integration in this repository release.
- The “Add & Test a Resource” area is a browser-only demonstration. It does not publish or permanently save listings.
- Search filters the resource cards already present on the page; it is not yet a global search engine or live news feed.
- News entries are links to external publishers, not reproduced articles or an automatically updated news feed.
- Advertising, affiliate tracking and paid sponsorship placements are not active yet.

## Next development stages
1. Improve bilingual English/Urdu navigation and add Arabic support.
2. Build a secure owner-only publishing dashboard and persistent resource catalogue.
3. Connect a database and authentication only after reviewing the existing backend and protecting all secrets; never place service-role keys or passwords in frontend code.
4. Add curated regional and international directories, original free utilities, and a properly sourced news feed.
5. Integrate lawful advertising, affiliate partnerships and labelled sponsorships only after accounts, policies and consent requirements are configured.

## Responsible publishing
- Prefer official publisher and authorized download sources.
- Clearly identify external destinations, sponsored placements and affiliate links.
- Respect copyright, trademarks, software licences, privacy and provider terms.
- Never disguise ads as download buttons or use misleading countdowns.
- Check files and links before publishing; do not claim a resource is safe without evidence.

## Budget and revenue
The project starts with a zero-spend approach. No paid plan, service, domain, advertising spend or purchase should be activated without the owner's explicit approval. Free services have limits and may change. Traffic, earnings and unlimited free use are not guaranteed.
