# SAAD YOUSUF KAKAR ULTIMATE — SK Cyber Hub

A mobile-friendly digital hub for AI tools, apps, software, documents, games and technology news.

## Current starter
- Responsive dark cyberpunk/neon homepage
- Category directory and live client-side search
- Mobile and desktop layouts
- Clear notice for legitimate external links, copyright and advertising transparency

## Run locally
Open `index.html` in a browser. No build tools or paid services are required for this static starter.

## Publish with GitHub Pages
1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site. The public URL will be shown in the Pages settings.
