## Supabase setup and safety
The original Supabase configuration workflow is preserved. The site expects the project URL and a public anon/publishable key to be configured in the browser's Supabase setup dialog. Never enter a Supabase service-role key or database password in the website. Database Row Level Security and server-side role checks must remain enabled. Admin access is granted only when the signed-in user's `profiles.role` is `admin`.

If the configuration is missing on a device, that browser may show the Supabase setup notice. Browser local storage is device/browser-specific; configuring one phone does not automatically configure another.

## Responsible publishing and monetization
- Prefer official publisher and authorized download sources.
- Clearly label external destinations, sponsored placements and affiliate links.
- Respect copyright, trademarks, software licences, privacy and provider terms.
- Never disguise ads as download buttons or use misleading countdowns.
- Advertising, affiliate tracking and paid sponsorship placements are not activated just because the disclosure page exists; they require separate provider approval and configuration.
- No earnings, traffic level or unlimited free usage are guaranteed.

## Budget
The project starts with a zero-spend approach. No paid plan, service, domain, advertising spend or purchase should be activated without the owner's explicit approval. Free services have limits and may change.
